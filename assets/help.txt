
General key mappings:

  F5     : Toggle fullscreen
  Ctrl+u : Delete to beginning of line
  Ctrl+n : Switch to next buffer
  Ctrl+p : Switch to previous buffer

Normal mode:

  Escape: Show menu
  Ctrl+c: Copy
  Ctrl+v: Paste
  Ctrl+z: Undo
  Ctrl+y: Redo
  Ctrl+f: Search
  Ctrl+s: Save buffer
  Ctrl+x: Quit buffer/editor if no content
  Ctrl+X: Force quit buffer/editor if no content

  Explorer :

    Ctrl+b          : Toggle Explorer
    Ctrl+n          : Create file/directory
    Ctrl+d / Delete : Delete file/directory
    Ctrl+f          : Search for files in current directory
    <TAB>           : Move to next file match
    <S-TAB>         : Move to previous file match

Vim mode (Not really):

  'm' Show menu
  's' Save buffer
  'q' Quit
  'Q' Force Quit
  'f' Toggle fullscreen
  '/' Search

  Explorer :

    'E'     Toggle Explorer
    'a'     Create file/directory
    'd'     Delete file/directory
    '/'     Search for files in current directory
    <TAB>   Move to next file match
    <S-TAB> Move to previous file match

Configuration:

  make sure you set the $HOME variable

  config file :

    Open the menu and choose open config

    Or use another text editor (pls don't use vscode)
    Config file: "$HOME/.config/texteditor/texteditor.conf"

  You can only customize the properties that already exits
  in the file (Or modify the source code)!
  Lines starting with '#' are ignored

Command line 

  Arguments:
    <file>       : open a file
    <directory>  : open a directory

  Options:
    -v           : Show the version
