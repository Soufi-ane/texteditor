
Normal mode:
  escape: show menu
  Ctrl+f: toggle fullscreen
  Ctrl+s: Save the file
  Ctrl+x: Quit

Vim mode:

  'm' show menu
  'q' Quit (I made that decision)
   0.01% of vim stuff is available

Configuration:

  make sure you set the $HOME variable
  open the menu and choose open config

  or use another text editor (don't use vscode)
  Config file: "$HOME/.config/texteditor/texteditor.conf"

  You can only customize the properties that already exits
  in the file!
  Comments starting with '#' are ignored
