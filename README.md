# Texteditor
#### It's just a text editor

Install from source
-------------------
#### After installing the dependencies

- [Raylib](https://github.com/raysan5/raylib)
- build-essential

### Clone and Install.

    git clone https://github.com/Soufi-ane/texteditor.git
    cd texteditor
    make install

### Run
    texteditor

### Usage
> Press Escape to show the menu
