# Note
#### It's just a note taking app ... or is it !?

Install from source
-------------------
#### After installing the dependencies

- [Raylib](https://github.com/raysan5/raylib)
- build-essential

### clone and install.

    git clone https://github.com/Soufi-ane/note.git
    cd note
    sudo make install

--------------------
## Key Mapping

| **Key**       | **Action**               |
|---------------|--------------------------|
| `o`           | Open a note                  |
| `n`           | Create a new note                |
| `Esc`           | Go to normal mode                |
| `i`,`o`,`a`     | Go into insert mode
| `j`                | Go Down      |
| `k`         | Go Up              |
| `t`       |Edit title          |
